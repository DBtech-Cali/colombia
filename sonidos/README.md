# Carpeta `sonidos/`

Coloca aquí los siguientes archivos de audio (no incluidos en este
proyecto por derechos de autor). La aplicación ya está preparada para
usarlos automáticamente en cuanto existan:

| Archivo          | Cuándo suena                                   |
|-------------------|------------------------------------------------|
| `correcto.mp3`    | Al marcar una respuesta correcta                |
| `incorrecto.mp3`  | Al marcar una respuesta incorrecta              |
| `timer.mp3`       | En cada uno de los últimos 5 segundos del timer |
| `inicio.mp3`      | Música de suspenso mientras se lee la pregunta  |
| `victoria.mp3`    | En la pantalla final, con el equipo ganador     |

Si algún archivo falta, el juego funciona igual — simplemente no se
reproducirá ese sonido (no genera errores ni bloquea la aplicación).
