# Carpeta `imagenes/`

Coloca aquí las imágenes referenciadas en el campo `"imagen"` de cada
pregunta en `preguntas.json` (por ejemplo `imagenes/ibague.jpg`).

- Si una pregunta no tiene imagen, deja el campo como cadena vacía `""`.
- Si el archivo referenciado no existe o no carga, la aplicación muestra
  automáticamente una imagen de reemplazo elegante — no necesitas subir
  una "imagen por defecto" manualmente.
- Formatos recomendados: `.jpg` o `.webp`, idealmente livianos
  (menos de 300 KB) para que la app cargue rápido incluso sin internet.
